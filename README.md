# 动漫归档（anime-archive）

本仓库是运行在本机上的 dsh-superagent 实例的目标仓库。

- The agent listens to issues and comments that mention its account, opens a ticket for each
  authorized request, works in its own directory and branch, and answers in the original thread.
- Work starts only for GitHub logins on the policy allow list of that installation.
